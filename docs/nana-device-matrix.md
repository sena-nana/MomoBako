# Nana 宿主设备验收矩阵

Issue18 的离屏证据不能替代 Windows 真窗口和系统输入服务验收。当前主机仅执行编译、单元测试和 WGPU 离屏场景，以下项目保留为设备验收入口：

| 能力 | 当前状态 | 设备验收要求 |
| --- | --- | --- |
| 真窗口生命周期与状态恢复 | 已接入，待设备验证 | Windows 11 重启后检查位置、尺寸、最大化。逻辑按最小 960×600 写入，最大化保留上一帧正常几何；离屏测试不移动真窗口 |
| 拖放与文件对话框 | 待设备验证 | 资源管理器拖入文件/目录，拒绝无效路径并记录错误。拖出文件已在 Windows 上发起系统拖放，待真窗口拖到资源管理器 |
| 剪贴板、外部打开和目录揭示 | 已接入，待设备验证 | 复制进系统剪贴板；用默认程序打开文件和网址；在资源管理器中定位。拖出文件已接通，待设备验证 |
| 托盘与关闭确认 | 已接入，待设备验证 | 最小化到托盘隐藏窗口且不退出。提示 MomoBako。左键、双击和「打开 MomoBako」显示窗口，「退出」结束进程。关闭确认文案已有单测；托盘点击仍待真窗口 |
| IME、快捷键与焦点顺序 | 待设备验证 | 中文输入、Tab/Shift+Tab、Esc、全局快捷键 |
| UIA / AccessKit | 待设备验证 | 检查角色、名称、状态、禁用控件和高对比度主题 |
| 离屏 Runtime/WGPU | 已接入自动化 | 运行 `cargo test -p momobako-nana --test offscreen_acceptance -- --nocapture` |
