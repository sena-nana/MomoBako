# Nana 宿主设备验收矩阵

Issue18 的离屏证据不能替代 Windows 真窗口和系统输入服务验收。当前主机仅执行编译、单元测试和 WGPU 离屏场景，以下项目保留为设备验收入口：

| 能力 | 当前状态 | 设备验收要求 |
| --- | --- | --- |
| 真窗口生命周期与状态恢复 | 待设备验证 | Windows 11，重启后检查位置、尺寸、最大化状态 |
| 拖放与文件对话框 | 待设备验证 | 资源管理器拖入文件/目录，拒绝无效路径并记录错误 |
| 剪贴板、外部打开和目录揭示 | 已接入，待设备验证 | 复制进系统剪贴板；用默认程序打开文件和网址；在资源管理器中定位。拖出文件仍未接通 |
| 托盘与关闭确认 | 待设备验证 | 最小化到托盘仍未接通。关闭确认文案已有单测；左键恢复和菜单退出仍待真窗口 |
| IME、快捷键与焦点顺序 | 待设备验证 | 中文输入、Tab/Shift+Tab、Esc、全局快捷键 |
| UIA / AccessKit | 待设备验证 | 检查角色、名称、状态、禁用控件和高对比度主题 |
| 离屏 Runtime/WGPU | 已接入自动化 | 运行 `cargo test -p momobako-nana --test offscreen_acceptance -- --nocapture` |
