# Nana 与 Vue 对照

原生壳层以 Vue 界面为参照，但目标是正确，不是逐像素复刻。取舍的优先级：

1. 功能、数据和状态正确：设置真正生效，交互结果正确，空、错、禁用、加载各状态都对。
2. 符合 `DESIGN.md` 的设计意图，并沿用 Vue 的结构层级和文案。
3. 像素细节。

Vue 的缺陷、死代码和意外的层叠效果不照抄，按设计意图实现，并记在本页。

## 对照方法

- Vue 侧在本机的 `tmp/vue-mock`（`tmp/` 被 git 忽略，不在仓库里）：用 `@tauri-apps/api/mocks` 模拟 IPC，渲染 `src/` 的真实页面，在无头 Edge（与 WebView2 同内核）里截图。先在仓库根目录用 `yarn vite --config tmp/vue-mock/vite.config.ts` 起 Vite（端口 1420），再用 `bash tmp/vue-mock/shoot.sh <场景> [light|dark] [宽] [高]` 截一张，`shoot_all.sh` 批量截浅色、深色和 1200×800、960×600，图在 `tmp/vue-mock/shots/`。场景登记在 `tmp/vue-mock/scenes/*.ts`，夹具在 `fixtures.ts`，命令应答在 `ipc.ts`。
- Nana 侧用 `scene_shots` 按场景名出图和节点清单，命令和输出位置见 [离屏验收证据](./nana-offscreen-evidence.md)。场景定义在 `src-nana/src/shell/acceptance_*.rs`，和 Vue 场景同名。截图前先把视图量到尺寸后发回的消息（播放条宽、文件列表宽）归约几轮，截到的是稳定后的画面。
- 有仓库的场景从 `acceptance_base.rs` 的共用底子起步，对应 Vue 夹具 `base()`：照产品启动依次送回资源库列表、同步、仓库摘要、首屏目录和侧栏的读取结果，侧栏计数、目录树和文件列表都由这些结果算出。场景要别的条目、目录树、播放集、播放器或仓库时改底子的字段，和 Vue 场景改 `scene.entries`、`scene.playlists` 一样。缺失仓库的 `missing` 场景不用底子，直接送一条缺失的资源库。
- `python tmp/vue-mock/compare.py <场景>` 出单个场景的并排图、差异热图和差异像素比例，`report.py` 对两边同名的截图批量出对照页。比例只用来发现问题，不作为通过标准。

## 全局取舍

**颜色合成。**
- NanaUI 在线性空间混合（见 NanaUI `docs/reference/text-engine.md`），Chromium 在 sRGB 空间混合。带透明度的主题角色（强调浅底、悬停底、浅红浅绿底）在 Nana 里更亮，深色主题下更明显。主题角色保留 NanaUI 的设计，不为对齐改动。
- 例外：Vue 用整块 `opacity` 盖在已知不透明底色上的地方（禁用态、色块外圈、播放条淡化），改用 `SemanticColorMix::new(前景, 底色, 比例)` 直接在 sRGB 通道混。
- 纯黑遮罩：线性空间里是把底色乘以 `1 - α`。要和 Vue 的 45% 黑一样暗，不透明度取 `linear_scrim_alpha(0.45) = 1 - 0.55^2.2 ≈ 0.732`。对话框的遮罩是主题的效果令牌 `modal_scrim`，`appearance.rs` 按这个换算写进去；背景模糊是 `modal_scrim_blur`，照 CSS 写 2。

**按钮。**
- Lilia 全局样式 `input, button, select { height: 32px }` 会压过组件自己声明的尺寸，例如 26px 的筛选芯片、日志芯片、适应/填充分段，以及 24px 的分组标题按钮。这种情况视为层叠缺陷，按组件声明的设计值画。没有声明尺寸的普通按钮和下拉照 32px 画。
- 侧栏行按声明的 28px 画（Vue 实际渲染为 32px），所以下面各组比 Vue 上移约 20px。
- 只写了裸类名、在 `src/styles` 里没有任何样式的按钮（`primary`、`ghost`、`ghost danger` 等），Vue 渲染成透明底、正文色。Nana 按 DESIGN.md 5.1 画：主操作用低饱和强调色，危险操作用低饱和红，普通操作透明。

**圆角。**
- 圆角半径基数来自设置（0–20，默认 8）。xs 到 2xl 分别是基数的 0.5、0.75、1、1.25、1.5、2 倍（`theme_map::corner_metrics`），2xl 是主题的 `RadiusTier::Xxl`。
- Vue 用 `--radius-2xl` 的大块表面都写 2xl 档：文件卡和详情卡、预览页、播放条、播放集面板，以及插件、日志和搜索页的工作台面板（`.search-workbench__panel`）。改了圆角半径重新装主题，这些表面跟着变，不用重建。
- 「平滑」圆角是主题的 `CornerShape::SQUIRCLE`（CSS `superellipse(2)`），「普通」是圆弧。

**关闭窗口。** 和 Vue/Tauri 一样直接退出，只有存在未保存修改时才先确认。

## 没照抄的 Vue 缺陷

### 壳层与侧栏
- 文件面板收的是全局 `error`：任何失败（定位失败、读素材详情失败、刷新文件夹树失败……）都把文件列表换成红色状态框，和侧栏状态区重复，列表也看不到了。Nana 的文件列表只显示文件区自己的失败（自己发起的目录读取和文件变更），别的失败只在侧栏状态区。
- 删除资源库、删除文件夹的选项卡片被全局 32px 高度压扁，标题和说明叠在一起。
- 智能文件夹对话框的最大高度是 72vh，800 高的窗口下底部「取消 / 创建」被裁掉。
- 启动日志时间用了未定义的 `--text-subtle`。
- 文件夹树的展开箭头底色盖住了树的引导线。
- 资源库切换按钮的无障碍名只有「资源库」，不含仓库名。
- 添加菜单的 160px 宽被 `.ctx-menu` 的最小宽度覆盖。
- 刷新文件夹树途中换了仓库，Vue 后半段的重读按当时的活动仓库读，会落到新仓库上；Nana 作废这一轮。
- 换仓库时 Vue 不改当前面板：在回收站、智能文件夹或播放集面板上换仓库，面板留着，回收站面板接着显示新仓库的根目录（不是回收站），智能文件夹和播放集面板是空的。Nana 换仓库时这三个面板回到文件面板。

### 文件页
- 导入菜单用了未定义的 `--panel-bg`，退回到 `#15171a` 深色底，字看不清。
- 960×600 下面包屑「根目录」逐字竖排，分隔线压到卡片上。
- `.files-list` 的网格行被拉伸或挤压。
- 详情预览是透明底白图标，浅色主题下看不见。
- 文件卡 `overflow: hidden` 把导入菜单裁掉。
- 导出对话框缺少输出路径，已补上。
- 列表模式在 960 宽下标题列被压到 0、内容溢出卡片；Nana 给标题至少留 80px。
- 右键子菜单离分组 4px，中间是父菜单的内边距，不属于 `.ctx-menu__slot`：指针慢慢移过去时 `:hover` 断一下，子菜单闪关。Nana 的子菜单连同这 4px 接缝整块接住指针，在分组和子菜单之间、子菜单里移动都不收起。
- 回收站里的「缩略图」分组是禁用的，但 `.ctx-menu__slot:hover` 不看按钮禁用，悬停照样弹出子菜单，里面的项还能点。Nana 禁用的分组不展开。
- 来源目录的「创建播放列表」失败时（缺歌单标识、建播放集或加入条目出错），`selectContextMenuItem` 只 `await item.onSelect()`，异常没人接，界面上什么都不显示。Nana 照 `runPlaylistAction` 在本地建播放集，失败写进文件列表的错误。

### 搜索与筛选
- 筛选芯片按设计值 26px 画；结果行高度按内容决定。
- 高级区的宽输入框填满格子（Vue 卡在 120px 宽，占位文字被截断）。
- 占位文字用弱化色（Vue 是浏览器默认的 `#757575`）。
- 手动加的颜色和形状始终有芯片，可以单独点掉。
- 搜索失败时显示真实错误，不再叠一个「等待搜索条件」。
- 搜索跑完没有命中时，空状态写「没有匹配的文件」和所在范围（没有筛选条件时是全部资源库，有筛选条件时是当前资源库的名字）；Vue 仍写「等待搜索条件」。

### 预览与播放
- 唱片按视口定尺寸，在预览框里溢出、被裁成方块，歌词栏也被裁掉。
- 播放请求被暂停打断时，Vue 把它当错误显示。
- 文本按字节截断时切开半个字符，留下替换符。
- 压缩包预览用了未定义变量，浅色主题下也是深色面板。
- 播放条的宽排版网格在窄栏里溢出，断点只看窗口宽度；Nana 在窗口不宽于 1120px，或者播放条自身窄于宽排版的下限（562px）时切换三行排版。
- 播放集条目标题被全局按钮样式居中。
- 自动播放失败后，图标仍显示「暂停」。
- 在 ASMR 资源库里打开音频预览，文件工作台和预览页上下同时出现，工作台里的播放条还显示「未选择播放内容」；Nana 只显示预览页。
- 文件预览里的音视频失败（读不出、认不出格式、解码失败），Vue 只在播放条第二行写一行弱色小字，预览框里照旧是唱片舞台或黑底。Nana 照 Vue 预览插件（`audioPreview.js`、`media-preview`）的失败浮层，在预览框里写红色标题「无法预览该音频」（视频是「无法预览该媒体」），下面一行原因，包括 Nana 自己的「没有原生解码器」和各格式的「解码失败」。播放条装不上同一个文件、写回的失败也这样显示。预览和播放条共用同一个解码，坏的 wav、mp3、flac、ogg 报它自己格式的原因，不再被说成没有解码器。
- 新建播放集失败时 Vue 只留着对话框、没有任何提示（请求失败成了没人接的 Promise 拒绝），也没有处理中状态，可以重复提交。Nana 等结果回来再关对话框，处理中禁用按钮、不能关，失败把原因写在对话框里。

### 设置、插件与日志
- 日志追踪滚动的是 `.logs-workbench__list` 本身，但列表不定高（只有 `min-height: 360px`），实际不会滚动，记录一多页头和筛选就跟着整页滚走。Nana 照 Vue 的结构让页面主体（`.workspace-page__body`）和列表都能滚，再按意图给列表定高：面板至少撑满主体，列表在筛选下面分走剩下的高度、自己滚动，追踪时跟随末尾，暂停时停在原位；窗口放得下时主体不随列表里的日志滚动。
- 日志列表的最小高有意偏离 Vue 的 360，收到 72（`admin_logs_view::LIST_FLOOR`），为的是保证追踪状态下最新记录可见：照 360 的话 960×600 和 960×480 都放不下，追踪时最新一条落在主体可视区下面，要滚一下页面才看得到。现在列表在主体剩余的高度里伸缩，960×600、960×480 下主体不滚，列表跟到末尾时最新一条的消息就在可视区里（单行消息的卡片从消息行到底边约 70，960×480 下筛选以下还剩 74）；窗口矮到连 72 都放不下时主体才滚。1200×800 下列表本来就比 360 高，表现不变。
- 文件导入、Eagle 导入工具页的 `tool-page-shell` 类全仓库没有 CSS。
- 圆角滑杆用了 `appearance: none`，轨道不可见。
- 设置数据刷新成功后，旧的错误提示不会清掉；Nana 刷新成功会清掉。

## 已知差异

### 交互
- 右键子菜单照 Vue `.ctx-menu__slot:hover` / `:focus-within`：指针或键盘焦点进到分组那一行（含子菜单）就展开，都离开就收起，没有延迟；点分组不收起，按下时焦点落在分组上，指针移开也留着；Tab 进分组展开，再 Tab 走进子菜单。指针和焦点各在一个分组里时，Vue 两个子菜单叠着显示，Nana 只显示指针所在的那个。
- 所有对话框都响应 Escape、点外面和关闭位（处理中都不关）。Vue 手写的 `.modal-overlay` 对话框（删除资源库、文件夹、智能文件夹、播放集等）都不响应 Escape，只有删除插件用的 Lilia `ConfirmDialog` 响应；这里一致响应。
- 对话框打开时框架把焦点放进对话框（第一个可聚焦的控件，确认框是「取消」），关掉后焦点回到打开前的位置。Vue 手写的对话框不管焦点；Lilia `ConfirmDialog` 有焦点陷阱，危险口气时先聚焦「取消」。
- 正在用输入法组合时，新的对话框等组合结束再打开（一激活就会拿走焦点、打断组合）。
- 同时打开的浮层只显示一层：关闭确认最先，其后是原来浮层槽位里的对话框、弹层和菜单，文件页的导出和文件对话框最后（原来画在主区里，压在浮层下面）。
- 点菜单外面关闭菜单时，这次点击不会穿透到下面的控件；右键别处只关菜单、不重新打开；滚动、缩放、失焦不会自动关菜单。
- 导入用应用内的路径对话框（Vue 用原生文件选择器）。
- 播放集条目从拖动柄和行的留白拖动排序；按在扩展名方块、标题、播放和移除上是点击。Vue 整行都能拖，在按钮上按下拖动也开始拖动。NanaUI 的 `ReorderList` 按下行就抓走指针，一行只能标一块不开始拖动的区域，见「NanaUI 缺口」。
- 框选只能选到已经建出来的卡片（视口加上下各 240px），选不到滚出视口很远的行。
- 瀑布流各列先按平均高度估算卡片高度，滚动中测到真实高度后，滚动条可能小幅跳动。
- 来源登录更新已有仓库以后，Vue 先 `refreshRepositoryWorkspace()`（读列表、把当前仓库原地同步一遍）再 `selectRepository(目标)`；Nana 合成一次：读列表，读完直接选目标仓库，不先同步当前仓库。
- 任务弹层的仓库操作行：
  - 多选删除和还原在 Vue 里逐条调用，进度写「正在处理 {名称}」；Nana 一次协议处理完，写「准备处理 N 个条目」，等待时往上爬。
  - 下载目录在 Vue 里先分页列出目录里的全部文件，进度写「正在处理 N 个文件」，曲目列表放进载荷；Nana 不列目录，停在「准备下载目录」，载荷里没有 `tracks`。
  - Vue 的爬升定时器会把更新到 88 以上的值压回 88（更新和完成总在同一拍，看不到）；Nana 不往回压。
  - 「同步资源库」「导入资源库」「配置网易云缓存」「导出资源库」在 Vue 里也有进度行，但入口函数（`syncActiveRepository`、`importExistingRepository`、`configureNeteaseRepositoryCacheInWorkspace`、`exportCurrentRepository`）没有界面调用方，Nana 不做。
- 刷新文件夹树要同步整个仓库。Vue 在整轮刷新期间把文件列表换成「正在读取目录」；Nana 在同步和重读期间照常显示列表，进度写在侧栏状态区，最后重读目录时列表才显示读取中。刷新按钮除了 Vue 的「正在读目录」，在目录树自己读取时也换成加载图标并禁用。实现见 [壳层绑定式视图](./nana-shell-view.md) 的「全局状态区」。

### 外观
- 侧栏、文件页和菜单的图标用 Tabler（Vue 用 Lucide），个别图形不同。预览、播放条、播放集页、设置、插件、日志和动作页把 Vue 用到的 lucide 源登记成产品图标（`player_icons.rs`、`admin_icons.rs`），形状和 Vue 一致。
- 对话框统一用 NanaUI `Dialog` / `ConfirmDialog`（行为优先）。距顶 12vh、最高 72vh、`--radius-xl`、三段内边距和两条分隔线、遮罩的暗度和模糊、进退场照 Vue `.modal-overlay` / `.modal-card` / `.dialog-card__*` 写进主题配方（`appearance.rs`）；宽度、危险口气和标题前的图标照各对话框的 Vue 模板和宽度类。截图对照下卡片的位置、宽度和分隔线在 1px 内。还剩的差异：
  - 卡片没有 Vue 的 1px 透明描边：内容整体上移 1px，卡片矮 2px。
  - 导出对话框的标题行矮约 2px：Vue 的 24px 关闭钮把那一行撑到 24，NanaUI 的关闭位不撑高标题行（确认框忙碌时藏起关闭位，正文不跳），最小行高按没有关闭钮的对话框取 Vue 正文的行盒 21.7。
  - 投影是主题的浮层投影 `0 14px 30px`，深色 45% 黑、浅色 28% 黑；Vue `.modal-card` 两个主题都是 `0 14px 40px` 45% 黑。卡片上下外缘的阴影比 Vue 收得快，浅色主题下也更淡。
  - 删除插件的确认框在 Vue 里是 Lilia `ConfirmDialog`（`UiDialog`：最高 76vh、`--radius-md`、没有分隔线、内边距 14/16/8），Nana 和别的对话框一样用 `.modal-card` 的配方；宽度、危险口气、标题前的警告三角和按钮照 Vue。
  - 建文件、新建文件夹、移动和三种导入在 Vue 里没有对话框（工具栏输入框、拖放、原生选择器）。Nana 的这几个对话框用 `.modal-card` 的宽度，标题前的图标按动作取：建文件 file-plus、新建文件夹 folder-plus、移动和导入 folder-open、ZIP 导入 archive。
  - 新建播放集的两个字段之间留 12，和别的对话框一样；Vue 的 `.playlist-dialog` 没写样式，两个字段贴在一起。
- 二维码按 `qrurl` 重新编码，内容和 Vue 相同，但模块排布不同。
- 勾选框选中时是强调色底上的「✓」（Vue 是浅色底上强调色的小方块）。NanaUI 的勾用主题配方里「强调色上的字色」，浅底上看不见。
- Select 不能按最长的选项定宽：日志页的仓库筛选外框宽 180（Vue 是 188），里面的下拉框最小宽 122。

### 数据
- 标签菜单没有仓库级标签组；智能文件夹的摘要行省略了。
- `foreign-tool`（第三方插件自己的工具页）只画页头和说明。Vue 在这里直接挂插件组件，原生壳层不运行插件的 Vue 组件。
- 插件清单声明的预览（`contributes.preview`）在 Vue 里要加载插件前端的 `dist/register.js`，由它 `registerPreview` 的 Vue 组件绘制，Nana 不运行插件前端，也就不登记这些贡献。随附插件（媒体、音频、文本、Office、压缩包、三维模型）声明的扩展名都由内置视图接手；只有第三方插件认得的扩展名照 Vue 没有预览插件时的样子，预览框只画缩略图或类型图标，不写字。原来给不能绘制的贡献写的「原生预览 · 名称 · 视图 id」随登记一起删掉。
- Vue 没有入口的设置卡已从设置页移除：缩略图缓存上限、默认播放器类型（`default_playlist_player_type_id`，不是设置页上的「音频播放」）、关闭行为、「保存应用设置」按钮，只为它们存在的消息和草稿也一并删掉。设置字段本身保留：缓存上限照旧校验和保存，默认播放器类型照旧读写，关闭行为照旧由关窗流程读取。主题改动后立即写入设置文件。
